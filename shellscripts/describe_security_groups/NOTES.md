# describe_security_groups.sh 機能メモ

<!-- ここにシェルスクリプトの機能・処理内容を書いていく -->
- アカウント内に存在するセキュリティグループを取得し、ルールをcsvに出力する
- csvはフォーマットを指定できるようにする。デフォルトでは[SG名、Direction、プロトコル、ポート、許可範囲、Description]の列の順で、ルールを下に行で追加していく。空白セルも挿入できるようにする。
- ソートや文字列のフィルターなどもオプションで利用できるようにする
- 結果の出力ファイル名もオプションで指定できるようにする
- リージョンをオプションで指定できるようにする（デフォルトはCLI設定のリージョン）
- ルールがインバウンド（Ingress）かアウトバウンド（Egress）かを列で区別できるようにする
